# Архитектурные заметки (черновик)

Решения, принятые в ходе обсуждения MVP Scope. Будут формализованы на этапе Architecture.

## Запуск агентов

- Claude Code CLI в headless-режиме (`claude -p`), не SDK
- Подписка Max, не API (pay-per-token)
- Стриминг через `--output-format stream-json`
- Персистентность диалогов через `--continue` / `--resume`

## Оркестрация

- Оркестрация агентов — своя, не нативные agent teams
- Граф зависимостей шагов определяет параллелизацию
- Каждый агент — отдельный процесс `claude -p`

## Инфраструктура

- Kubernetes, cloud-agnostic
- Бэкенд — pod в K8s
- Фронтенд — pod или статика
- Worker pods — контейнер с Claude Code CLI + клонированный проект
- На каждом worker pod — лёгкий агент-демон (HTTP/WebSocket), принимает команды от бэкенда
- БД — для хранения задач, дизайнов, планов, состояния чатов

## Коммуникация бэкенд ↔ worker

- Агент-демон на worker pod принимает команды по WebSocket
- Стримит результаты работы Claude Code обратно бэкенду

## Внешние зависимости

- Claude Code CLI (подписка Max)
- GitHub API (коммиты, PR, мониторинг комментариев)
