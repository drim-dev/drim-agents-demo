# Дизайн: Дашборд

> Статус: **Не начат**

## Скоуп

Kanban-доска с колонками: Design, Plan, Implementation, Review, Done. Карточки задач (имя, краткий статус). Перемещение карточек только через действия (approve, generate и т.д.), без drag-drop. Детальный вид задачи: дизайн-документ, план с чекбоксами, статусы шагов, история чата, ссылка на PR, артефакты. Real-time обновления через SignalR. Логирование переходов с таймстампами. Адаптивный дизайн: Kanban как вертикальный список на мобильных, responsive CSS без отдельного мобильного UI.

**Требования:** FR-6, FR-7
