# Дизайн: Стадия Implementation

> Статус: **Не начат**

## Скоуп

Автостарт при одобрении плана. Worker-поды (эфемерные) для выполнения агентов. Распределение шагов по графу зависимостей: независимые шаги параллельно. Авто-коммиты кода и прогон тестов на каждом шаге. Взаимное код-ревью между агентами. Прогресс через чекбоксы в плане. Пользователь может писать инструкции в чат во время реализации. Остановка всей реализации. Self-recovery агента при ошибке, эскалация через чат при неуспехе. Автопереход на Review по завершении всех шагов.
